# STT-MRAM

## 架構

1. MTJ：由固定層、絕緣層、自由層組成。假設固定層在上。
2. 電晶體：一個電晶體負責控制寫入或讀取的電流，當要讀寫時就會通電。
3. Word Line(WL)：連接到電晶體，當要寫入或讀取時就會打開。
4. Bit Line(BL): 在MTJ上方，負責寫入與讀取。
5. Source Line(SL): 在MTJ下方，也負責寫入與讀取。
6. 有導線從MTJ上方的BL穿過MTJ至下方的SL，當寫入或讀取時會通電流。
7. 下電極：在MTJ下方完全接觸，為了讓電流均勻地流過整個 MTJ

## 寫入原理

- 寫入0時：先打開WL，然後讓電子從SL流向BL (從自由層到固定層)，當電子穿過自由層想要通過固定層時，自旋方向與固定層相反的電子就會被反射回來，這些自旋方向相反的電子會把自由層的電子轉成自旋方向相反，最終自由層的自旋方向會變得跟固定層相同(P)。
- 寫入1時：先打開WL，然後讓電子從BL流向SL (從固定層到自由層)，只有跟固定層自旋方向相同的電子可以流到自由層，這些與固定層自旋方向相同的電子會把自由層的電子轉成自旋方向相反，最終自由層的自旋方向會變得跟固定層相反(AP)。

## 讀取原理

- 巨磁阻效應TMR：當固定層與自由層自旋方向相同時，電阻會比較低; 當固定層與自由層自旋方向相同時，電阻會比較大。透過這個差異就可以作為0或1的代表。
- 測量：先打開WL，然後在從BL往SL施加一個微小的電流，感測放大器負責測量輸出：一端接BL，一端接參考線(基準電壓)，電阻小輸出0，電阻大輸出1。

## 缺點

- 有可能會有Read Disturb: 在讀取時電流太大可能不小心改寫到儲存的位元。
- 由於寫入與讀取皆是透過BL與SL施加電流，加上MgO絕緣層極薄，容易被貫穿，耐久性不高。

## FAQ

1. 關於巨磁阻效應，為什麼平行的自旋會讓電阻比較小？反之亦然
2. 為什麼在寫入時，一群同自旋方向的電子跑到自由層裡面會讓他的自由層的自旋方向相反，而不是相同？
